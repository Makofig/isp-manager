## 📋 Diagnóstico de la v1.0

### ¿Qué es InterSys?
Sistema de gestión para ISP (Proveedor de Servicios de Internet) que administra clientes, planes/contratos, access points, pagos, cuotas y deudores. Integra MercadoPago para pagos online.

### Stack Actual
| Capa | Tecnología |
|------|-----------|
| Backend | Laravel 12 + PHP 8.2 |
| Auth | Laravel Jetstream 5 (teams, 2FA, API tokens) |
| Frontend | Livewire 3 + Blade + Tailwind CSS |
| PDF | DomPDF 3.1 |
| Pagos | MercadoPago SDK 3.8 |
| Build | Vite 7 |

### 🔴 Problemas Críticos Identificados (Verificados por 4 agentes independientes)

#### Bugs que Rompen Producción
1. **`generarMensuales()` está roto** — Consulta `Client::where('activo', true)` pero la columna `activo` no existe en BD ni en migración. **Lanza error SQL en producción.**
2. **Relación `plan` inexistente** — `paymentController` usa `$cliente->plan->costo` pero el modelo tiene `contract()`. **Fatal error en generación de cuotas.**
3. **`crearLinkPago()` ignora sus parámetros** — El servicio de MercadoPago tiene valores hardcodeados (precio fijo $1000, external_reference estático, URLs a httpbin.org). **Todos los links de pago son idénticos/datos de prueba.**
4. **Case sensitivity en controllers** — Routes usan `ClientController::class` pero el archivo es `clientController.php`. **Funciona en Windows, FALLA en Linux (producción).**

#### Frontend/Build
5. **Tailwind cargado 3 veces** — CDN en layout + Vite + cada componente feature carga otro CDN. **FOUC, estilos conflictivos, pages rotas.**
6. **Componentes feature son HTML completo** — `client.blade.php`, `contracts.blade.php`, `quota.blade.php`, `access-point.blade.php` tienen `<html><head><body>` anidados con título "Stitch Design" (copia de template). **HTML inválido.**
7. **Navegación mobile rota** — Solo Dashboard aparece en menú hamburguesa. **7 de 8 secciones inaccesibles en móvil.**

#### Arquitectura
8. **Sin capa de servicios consistente** — La lógica de negocio está en controllers. Solo existe `MercadoPagoService`.
9. **Sin Form Requests** — Validación inline en controllers, imposible de reutilizar.
10. **Sin Events/Listeners** — Pagos confirmados no disparan eventos (notificaciones, actualización de estados).
11. **Sin Queue Jobs** — Generación mensual de cuotas es síncrona (puede timeout con muchos clientes).
12. **Sin API Resources** — No hay capa de transformación para API.
13. **Sin Soft Deletes** — Clientes se eliminan permanentemente, sin recuperación.
14. **Sin auditoría** — No se registran cambios ni quién los hizo.

#### Base de Datos
8. **Naming inconsistente** — Tablas en español (`cliente`, `pagos`, `plan`) pero campos mixtos.
9. **Sin índices optimizados** — Búsquedas por IP, estado, fechas sin índices.
10. **Campos duplicados** — `activo` en controller pero no en migración. `cliente_id` vs `id_cliente`.
11. **Sin timestamps en algunas operaciones** — Cuotas sin tracking temporal adecuado.

#### Seguridad
12. **Sin autorización (Policies/Gates)** — Cualquier usuario autenticado puede hacer todo.
13. **Sin roles/permisos** — No hay distinción entre admin, operador, técnico.
14. **API sin rate limiting** — Rutas API desprotegidas.
15. **Webhook MP sin validar firma** — Vulnerable a falsificaciones.

#### UX/UI
16. **UI genérica de Jetstream** — Sin identidad visual propia.
17. **Dashboard básico** — Méricas sin contexto, sin acciones rápidas.
18. **Navegación plana** — 8 items de menú sin agrupación lógica.
19. **Tablas sin experiencia premium** — Sin ordenamiento avanzado, sin export CSV/Excel.
20. **Sin dark mode** — Solo tema claro.
21. **Sin estados vacíos** — No hay ilustraciones ni guías cuando no hay datos.
22. **Sin loading states** — No hay skeleton screens ni spinners.
23. **Formularios extensos** — Sin wizard, sin validación en tiempo real.
24. **Sin notificaciones en tiempo real** — No hay Pusher/websockets.

#### Código
25. **Tailwind duplicado** — CDN + Vite plugin (conflicto de versiones).
26. **Sin tests** — Cobertura 0%.
27. **Comentarios en español, código en inglés** — Inconsistencia.
28. **Código muerto** — Bloques comentados por todos lados.
29. **Sin PHPStan/Laravel Pint en CI** — Sin estandarización.

## 🎯 Visión v2.0: "Premium ISP Management"

Transformar InterSys de una herramienta funcional a una **experiencia premium de gestión ISP** que:
- Se sienta como un producto SaaS moderno (no como un proyecto interno)
- Sea visualmente impactante con dark mode, animaciones fluidas y diseño consistente
- Tenga arquitectura escalable con eventos, jobs y caché
- Ofrezca seguridad real con roles, permisos y auditoría
- Proporcione insights accionables, no solo datos

## 🏗️ Propuesta de Arquitectura v2.0

### 1. Arquitectura Hexagonal + DDD Ligero

```
app/
├── Domain/
│   ├── Client/          # Entities, Value Objects, Repositories interfaces
│   ├── Payment/         # Payment domain logic
│   ├── Contract/        # Contract/Plan domain
│   └── AccessPoint/     # Infrastructure domain
├── Application/
│   ├── Commands/        # CQRS Commands
│   ├── Queries/         # CQRS Queries
│   ├── Services/        # Application services
│   └── DTOs/            # Data Transfer Objects
├── Infrastructure/
│   ├── Persistence/     # Eloquent implementations
│   ├── Services/        # MP, PDF, SMS implementations
│   └── Notifications/   # Email, Push, WhatsApp
└── Http/
    ├── Controllers/     # Thin controllers
    ├── Requests/        # Form Requests
    └── Resources/       # API Resources
```

### 2. Nuevos Paquetes

| Paquete | Propósito |
|---------|-----------|
| `spatie/laravel-permission` | Roles y permisos |
| `spatie/laravel-activitylog` | Auditoría de cambios |
| `spatie/laravel-medialibrary` | Manejo de imágenes mejorado |
| `barryvdh/laravel-excel` | Export CSV/Excel |
| `laravel/horizon` | Monitoreo de queues |
| `pusher/pusher-php-server` | Notificaciones en tiempo real |
| `laravel/slack-notification` | Alertas a Slack |
| `livewire/volt` | Testing de Livewire |

### 3. Eventos y Jobs

```php
// Events
PaymentConfirmed → SendReceiptEmail, UpdateClientStatus, NotifyAdmin
QuotaGenerated → NotifyClients, CreatePaymentRecords
ClientBanned → DisconnectService, SendWarning
ClientCreated → WelcomeEmail, AssignDefaultResources

// Jobs
GenerateMonthlyQuotas (chunked, idempotent)
ProcessBulkPayments
SendPaymentReminders
GenerateStatisticsCache
```

### 4. Caché Inteligente

```php
// Dashboard metrics cacheadas 5 minutos
Cache::tags(['dashboard'])->remember('stats', 300, fn() => ...);

// Access point client counts cacheados
Cache::tags(['access-point'])->remember("ap:{$id}:clients", 600, fn() => ...);

// Invalidación automática vía model observers
```
